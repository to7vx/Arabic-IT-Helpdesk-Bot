# `@arabic-helpdesk/shared-types`

TypeScript types generated from the backend OpenAPI 3.1 spec.

Generated by `pnpm --filter @arabic-helpdesk/shared-types generate`, which runs `openapi-typescript` against `apps/api`'s `/openapi.json`. The output (`src/openapi.d.ts`) is checked in so consumers do not need to spin up the API to typecheck.

> **Status:** placeholder. The generation script and lockable types land alongside Phase 3 (API).
