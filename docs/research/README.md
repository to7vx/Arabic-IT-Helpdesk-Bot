# Research Notes

This directory contains the research that backs every ADR in `docs/decisions/`. Each note summarizes a focused investigation done during Phase 0 of the project. Notes are dated and link to primary sources so future maintainers can re-verify or extend the work.

| File | Topic |
|---|---|
| `arabic-nlp-models.md` | Encoder models for Arabic (AraBERT, MARBERT, CAMeLBERT) |
| `multilingual-embeddings.md` | Sentence embeddings for hybrid Arabic/English retrieval |
| `arabic-llms.md` | Generative Arabic LLMs (Jais, AceGPT) vs. hosted APIs (Claude) |
| `arabic-tokenizers.md` | Farasa vs. CAMeL Tools morphological segmentation |
| `saudi-pdpl.md` | Saudi Personal Data Protection Law compliance landscape |
| `competitive-landscape.md` | Open-source helpdesk alternatives and the Arabic gap |
