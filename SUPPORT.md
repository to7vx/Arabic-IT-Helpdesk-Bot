# Getting Support

A few ways to get help, in order of preference:

1. **Docs first:** https://arabic-helpdesk.dev — installation, configuration, NLP guide, ADRs.
2. **GitHub Discussions:** for "how do I…?" and design questions.
3. **GitHub Issues:** for reproducible bugs or concrete feature requests. Use the templates.
4. **Security disclosures:** see [SECURITY.md](SECURITY.md) — do **not** open a public issue.

## Commercial support

This project is community-maintained. If you need SLA-backed support, training, or paid customization, see `https://arabic-helpdesk.dev/support` for a list of independent providers. Listing is community-curated; the maintainers do not endorse any particular vendor.

## Status of issues

* `triage` — needs maintainer review.
* `accepted` — a fix or feature is welcome.
* `help wanted` — good entry point for new contributors.
* `blocked` — waiting on something external; the comment explains what.
